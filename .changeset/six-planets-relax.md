Add a visual settings panel (`Unravel: Open Settings`, and a gear icon on the
explain panel's title bar). It shows real detection status for Claude Code
and Codex (installed/not, with version), lists language models other
extensions have registered for `vscodeLm` mode as clickable chips, and lets
you switch auth mode, language, detail, model, and context lines without
touching `settings.json`.
